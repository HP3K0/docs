---
title: Integration checklist
description: Checklist to sign-off PeoplesPay Integration
---

We've put together a checklist of integration aspects to review before final sign-off to go live.

|Action|Importance|
|---|---|
|Verify applied transaction charges in accordance with merchant agreement (SLA)|Critical|
|Target the `status` field for merchant-side transaction status updates and cascading actions|Critical|
|Process repeated webhook notifications idempotently|High|
|Pass `externalTransactionId` when initiating transactions|High|
|Blacklist non-PeoplesPay IP address for webhook notification processing|High|
|(Card proceessing) Support DOM injection to render 3D Secure challenge for end-users|High|
|Confirm transaction data retrieval (via both API and merchant portal)|High|
|Store PeoplesPay transaction ID in merchant-side DB for sync and `externalTransactionId` fallback|Medium|
|Programmatic access to merchant account balance|Low|
|Cache authentication tokens for transaction execution|Low|

<Danger>
Correctly processing webhook notifications is crucial. Mistakes and errors here can seriously undermine your integration.
</Danger>
