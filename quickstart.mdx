Welcome to PeoplesPay! This guide will take you through the basics of collecting money (into your PeoplesPay account) as well as disbursing money (sending money to a customer from your PeoplesPay account).
This quickstart outlines these operations via the PeoplesPay API, so you will need to have access to that first.

## Prerequisites
<AccordionGroup>
  <Accordion title="Approved merchant account">

## Defining terms
Before we continue, let us define a few terms:
|Term|Meaning|
|---|---|
|Customer|The other party you complete an operation with (payer or recipient)
|Collection|An operation involving money being debited (taken) from a customer
|Disbursement|An operation involving money being credited (sent) to a customer
|Merchant|A user registered on PeoplesPay that performs collections and disbursements
|Wallet|Where money is stored, sent from or sent to

## Generate an access token
The first step to performing collections and/or disbursements on PeoplesPay is to generate an access token. These will be passed in the HTTP Authorization as a Bearer value. 

You issue an unauthenticated `POST` request to the `/hub/token/get` endpoint

```plaintext
curl
--location 'https://peoplespay.com.gh/peoplepay/hub/token/get' \
--header 'Content-Type: application/json' \
--data '{
    "merchantId": "63b59e40530000aec59a049f",
    "apikey": "93060047-0000-0000-0000-4dee28773a86"
}'
```

The collection request includes three fields, with one being optional: `merchantId`, `apikey` and `operation`. `operation` has a default value of `DEBIT`, which refers to the debit of a customer’s account to credit a merchant.

The response returns an access token valid for 30 minutes

## Initiate collection request
To initiate a collection via mobile money (check the Collections page for collecting from bank cards), you must specify the customer’s mobile network, their phone number along with the amount you’d like to collect. You can pass a custom transaction ID to track your operation, along with a URL to receive a webhook notification when the transaction status resolves.

```plaintext
curl 
--location 'https://peoplespay.com.gh/peoplepay/hub/collectmoney' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer eyJhbGciOiJIUzUxMiIsInR5cCI6IkpYVCJ9.eyJhcHBJZCI7IjY0MGFmZFE0NzA3MDBlZDdjYWE4ZDU5OSIsIm9wZXJhdGlvbiI6IkRFQklUIiwibGFzdHNlZW4iOiIyMDIzLTAzLTEwVDA5OjUxOjMyLjIyMFoiLCJpYXQiOjE3MzgzNzkzMzUsImV4cCI6MTczODM0MjkzNX0.2s2LpPrkLt5VF0bYR_vtrAhChxEkizLB61Ugqiz58r3yRVb9HeEJ7eJ0jOzwzHUdjgtslprbQHacPvwnw9aOHQ' \
--data '{
    "amount":1.2,
    "account_name":"1738340456",
    "account_number": "0553142293",
    "account_issuer": "mtn",
    "description": "test payment1",
    "callbackUrl": "https://webhook.site/0d511110-0ab1-40d3-be91-31a74bd592a5",
    "externalTransactionId": "running-a-test-on-1738340456"
    
}'
```

For a successfully initiated transaction, the response is as follows:
```json
{
    "code": "01",
    "success": true,
    "message": "Transaction Recieved for Processing",
    "transactionId": "67a0ea4c298ab35d935ae468",
    "date": "2025-02-03T16:09:48.884Z",
    "externalTransactionId": "running-a-test-on-1738598989"
}
```

As this collection will be performed via the mobile money channel, the `account_number` will receive a USSD prompt to authorize the payment.

## Bonus: disburse money
If the collection was successful, you’ll be able to perform a disbursement; this operation moves money from your PeoplesPay wallet to a mobile money wallet or a bank account.

As with collections, the first step is to generate an access token to perform the operation:
```plaintext
curl
--location 'https://peoplespay.com.gh/peoplepay/hub/token/get' \
--header 'Content-Type: application/json' \
--data '{
    "merchantId": "63b59e40530000aec59a049f",
    "apikey": "93060047-0000-0000-0000-4dee28773a86",
    "operation": "CREDIT"
}'
```
Note the value of the operation field; it must be set to CREDIT, to perform a disbursement. Then, use the returned token for the following request:

```plaintext
curl 
--location 'https://peoplespay.com.gh/peoplepay/hub/disburse'
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer eyJhbGciOwJIUzUxMiIsInR5cCI6IkpXVCJ9.eyJhcHBJZCI6IjY0MGnmZGE0NzA3NDBlZDdjYWE4ZDU5OSIsIm9wZXJhdGlvbiI6IkNSRURJVCIsImxhc3RzZWVuIjoiMjAyMy0wMy0xMFQwOTo1MTozMi4yMjBaIiwiaWF0IjoxNzMzMDIyMjUxLCJleHAiOjE3MzMwMjU4NTF9.gmCCwfnFsxmEtO19EOu69Bb2qUSOD9pzvxmyEazolyT_nM3xrt-Mc6G6l6W7jQJVDt1wALYv3hIFhe-O7VpX0g' \
--data '{
    "amount":0.1,
    "account_number": "0500720780",
    "account_name": "unknown",
    "account_issuer": "vodafone",
    "description":"test",
    "externalTransactionId": "123345",
    "account_type": "momo"
}'
```

The example above would send money to a mobile money account. If successful, the repsonse would look something like this:

```json
{
    "code": "00",
    "success": true,
    "message": "Transaction received and being processed",
    "transactionId": "67a0f8c10583b4700901ce30",
    "date": "2025-02-03T17:11:29.037Z",
    "externalTransactionId": "123345"
}
```
