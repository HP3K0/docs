Payments will sometimes fail, whether for collections or disbursements.

## Collections

Transaction failures for collections will vary by payment channel. 

### MTN Mobile Money
|Error message|Description|Suggested action|
|---|---|---|
|COULD_NOT_PERFORM_TRANSACTION|Transaction not completed, likely due to approval timeout.|Debit transactions have a 5-minute approval window. If the transaction times out, please retry the transaction to complete the debit|
|LOW_BALANCE_OR_PAYEE_LIMIT_ REACHED_OR_NOT_ALLOWED|A combination error, that largely covers insufficient wallet balance.|Retry the transaction; if the error persists, reach out to PeoplesPay support.|
|INTERNAL_PROCESSING_ERROR|This is a default or generic error code used when there is no specific error mapping. This predominantly occurs due to insufficient customer funds to complete the transaction. Also related to service denied or Wallet Platform is not reachable.| Retry the transaction, if possible.|
|NOT_ENOUGH_FUNDS|The payer does not have enough funds.|
|SENDER_ACCOUNT_NOT_ACTIVE|The MoMo wallet used for the transfer has not been activated.|Please contact MTN support to activate the wallet for transactions|
|PAYEE_NOT_FOUND|PeoplesPay OVA is temporarily unavailable.|This error generated when the business account is blocked or otherwise unavailable. Retry the transaction, or contact support.|


### Telecel Cash
|Error code|Description|Suggested action|
|---|---|---|
|INS-1|Internal Error|Re-attempt the collection. If the error persists, contact support.|
|INS-6|Transaction Failed|Re-attempt the collection. If the error persists, contact support.|
|INS-9|Request timeout|The payment request timed out; customers must approve the transaction in time, to complete a collection.|
|INS-15|Invalid Amount Used|Review the collection amount stated in the request, and re-attempt the collection.|
|INS-990|Customer Transaction Value Limit Breached|Customer wallets have a maximum daily limit for transaction value; limit has been reached.|
|INS-991|Customer Transaction Count Limit Breached|Customer wallets have a maximum daily limit for transaction count; limit has been reached.|
|INS-992|Multiple Limits Breached| More than one limit has been reached, for a customer's wallet.|
|INS-2006|Insufficient balance| Customer wallet does not have enough funds to complete the collection.|
|INS-2051|MSISDN invalid.|The phone number used for the collection is invalid. Check the number and re-attempt.|
