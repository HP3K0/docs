Webhook events are created and sent for updates to collection and disbursement statuses.


## Collections
For collections, the event payload has the following structure:

```json
{
  "eventId": "6a8fcecad33dc394480b8406",
  "amount": 0.1,
  "status": "failed",
  "date": "2026-08-27T05:44:27.748Z",
  "message": "MTN status: FAILED; COULD_NOT_PERFORM_TRANSACTION",
  "success": true,
  "code": "02",
  "externalTransactionId": "runningateston1787809465"
}
```
