Events are created within the PeoplesPay platform when specific conditions are met. Events are then delivered to webhook URLs as a <Badge color="blue">POST</Badge> request, which we refer to as a webhook notification. Currently, webhook notifications are delivered only for transaction status updates, to the `callbackUrl` specified during transaction initiation.

## The event object
<ResponseField name="id" type="string">ID of event</ResponseField>
<ResponseField name="eventType" type="string"><Tooltip headline="Event types" tip="Events can be of different types. The event object will specify what kind of event is emitted and delivered to a URL." cta="Refer to event types" href="/events/webhook-event-overview">Event type</Tooltip>.</ResponseField>
<ResponseField name="createdAt" type="string">ISO timestamp of event creation time.</ResponseField>
<ResponseField name="eventData" type="object">
Event data payload, containing details on the <mark>instance</mark>
</ResponseField>
<ResponseField name="deliveryStatus" type="enum<string>">
The status of the webhook notification's delivery to the webhook URL.

Available values: `DELIVERED`, `AWAITING_DELIVERY`, `DELIVERY_ATTEMPTED`, `FAILED`
</ResponseField>
<ResponseField name="destination" type="string">URL the webhook notification is delivered to.</ResponseField>
<ResponseField name="customerId" type="string">ID of customer the event was created for.</ResponseField>
<ResponseField name="customerType" type="enum<string>" default="merchant">
Type of the customer the event was created for.

Available value: `merchants`, `customers`, `donations`
</ResponseField>
<ResponseField name="deliveredAt" type="string">ISO timestamp at which the acknowledgement of webhook notification delivery was received on PeoplesPay.</ResponseField>
<ResponseField name="lastAttemptedAt" type="string">ISO timestamp of the most recent attempted webhook notification delivery.</ResponseField>
<ResponseField name="numberOfAttempts" type="number">Count of total attempted webhook notification deliveries.</ResponseField>


## Types of events
|Event type|Description|Payload|
|---|---|---|
|`transaction.status.updated`|This event type is created and delivered whenever a transaction status changes.|`eventData` is a [collection](/api-reference/collections#properties) or [disbursement](/api-reference/disbursements#properties)
