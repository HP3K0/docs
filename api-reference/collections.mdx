Collection transactions are initiated by calling the API to collect money from an end-user. We currently support mobile money and bank card payment channels. For a complete list of supported mobile money operators and card schemes, please refer to the [Collections overview]()

## The Collection object
There are two main collection object references. One is a truncated object delivered in the webhook event payload, the other is the full object included in the transaction history `data` object.

<Warning>
Toggle between the two objects using the dropdown in the upper right corner of your screen.
</Warning>

- `transaction.status.updated` - Fired when the status of a transaction is updated. See [event reference](/api-reference/events).

## Endpoints
|Method|Path|Description|
|---|---|---|
|<Badge color="blue">POST</Badge>|[`/hub/token/get`](/api-reference/endpoint/get-token)|Generate bearer token for collection request|
|<Badge color="blue">POST</Badge>|[`/hub/collectmoney`](/api-reference/endpoint/collect-momo)|Initiate collection via mobile money channel|
|<Badge color="blue">POST</Badge>|[`/hub/collectmoney/card`](/api-reference/endpoint/collect-card)|Initiate collection via bank card|
