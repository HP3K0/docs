Collection transactions are initiated by calling the API to collect money from an end-user. We currently support mobile money and bank card payment channels. For a complete list of supported mobile money operators and card schemes, please refer to the [Collections overview]()

## The Collection object
There are two main collection object references.
- One is a truncated object delivered in the webhook event payload,
- the other is the full object included in the transaction history `data` object.

<Warning>
Toggle between the two objects using the dropdown in the upper right corner of your screen.
</Warning>
