Welcome to the PeoplesPay API playground. Here, you can interact with our endpoints and perform HTTP requests.

Our API is RESTful, so you'll be right at home if you've got any experience with such APIs.

## A note on authentication
The Bearer token to pass in the Authorization header is generated upon successful authentication (i.e. login), except when performing operations such as collections and disbursements. For operations, the access tokens are generated using dedicated endpoints. See the [Get token](/api-reference/endpoint/get-token) page for more information.
